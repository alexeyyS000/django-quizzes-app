# Django Quizzes App

A web application for creating, managing, and taking tests and quizzes.

## Technologies

* Django
* Celery
* Redis
* Docker
* PostgreSQL
* HTML
* CSS
* JavaScript
* Bootstrap 5

## Implemented Features

* Developed a responsive user interface using Bootstrap 5;
* Implemented user authentication and personal dashboard functionality;
* Added multilingual support (Russian and English);
* Created a quiz and test-taking system with result tracking;
* Integrated PostgreSQL for data storage;
* Configured Celery and Redis for asynchronous task processing;
* Containerized the application with Docker for simplified deployment.
